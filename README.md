# La Cambuse

Prototype de plateforme web pour la méthode Cap — outil interne destiné aux intervenants et psychologues d'une association accompagnant des jeunes en difficulté.

Site statique (HTML/CSS/JS, aucune dépendance). La connexion est simulée : n'importe quel email/mot de passe fonctionne, il n'y a pas de vrai backend. Tout le contenu (documents, partenaires, commentaires) est factice, à des fins de démonstration du design et de la navigation.

## Lancer en local

Ouvrir `index.html` directement dans un navigateur, ou servir le dossier avec n'importe quel serveur statique :

```
python3 -m http.server 8080
```

## Déploiement

Site 100% statique, déployable tel quel sur Netlify, Vercel, GitHub Pages ou équivalent (aucune configuration de build nécessaire).
